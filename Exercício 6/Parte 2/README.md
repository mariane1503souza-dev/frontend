## Containers, Rows e Cols para Layout Responsivo
Nesta segunda parte do exercício, o index.html foi atualizado para incorporar os princípios de layout responsivo do Bootstrap, utilizando containers, rows e cols. Foram criadas seções de hero, categorias de produtos e destaques, garantindo que o conteúdo se adapte adequadamente a diferentes tamanhos de tela.
### Principais Implementações:
Seção Hero: Uma área de destaque na parte superior da página, utilizando um container-fluid para largura total e row/col para centralizar o conteúdo.

- **Categorias de Produtos**: Implementação de pelo menos três categorias de produtos, cada uma exibida em uma única coluna em dispositivos móveis (col-12) e em três colunas em desktops (col-md-4). Isso demonstra a flexibilidade do sistema de grid do Bootstrap.
- **Destaques**: Uma seção para produtos em destaque, seguindo a mesma lógica de responsividade.
- **CSS Externo**: A personalização da aparência da home page foi realizada exclusivamente no arquivo assets/css/style.css, sem o uso de CSS inline ou blocos <style> no HTML, conforme as boas práticas.
Essas modificações visam aprimorar a estrutura visual do site, tornando-o mais organizado e acessível em qualquer dispositivo.
