# MercadoTech - Pânico 6 Edition
## Visão Geral do Projeto
MercadoTech é um site de vendas de produtos de tecnologia com temática de Pânico 6, desenvolvido como exercício prático de HTML5, Bootstrap 5 e CSS3 responsivo. O projeto foi construído em cinco partes progressivas, desde a estrutura básica até a publicação final.

### Informações do Projeto

- **Nome da Empresa**: MercadoTech
- **Temática**: Pânico 6 (filme de terror)
- **Tecnologias Utilizadas**: HTML5, Bootstrap 5.3.0, CSS3
- **Estrutura**: Site estático com 5 páginas principais
- **Responsividade**: Totalmente responsivo (mobile-first)

### Páginas do Site

1. **index.html - Página Inicial**
**A página inicial apresenta a empresa com uma seção hero temática, categorias de produtos e destaques. Inclui**:
- Navbar responsiva com links para todas as páginas
- Seção Hero com chamada para ação
- Três categorias de produtos (Dispositivos de Vigilância, Gadgets de Sobrevivência, Acessórios Assombrados)
- Seção de destaques com 3 produtos em destaque
- Footer com informações de copyright

2. **produtos.html - Catálogo de Produtos**
**Página com o catálogo completo de 6 produtos temáticos**:
1.Máscara de Ghostface (Réplica Premium) - R$ 299,90
2.Câmera de Segurança Noturna 4K - R$ 1.499,90
3.Fone com Cancelamento de Ruído (Edição Limitada) - R$ 899,90
4.Lanterna LED Tática 10.000 Lumens - R$ 349,90
5.Smartwatch Robusto com GPS - R$ 749,90
6.Drone com Câmera 4K e Visão Noturna - R$ 2.499,90

**Cada produto é apresentado em um card com**:
- Título e descrição
- Preço
- Botão "Adicionar ao Carrinho"

3. **sobre.html - Página Institucional**
**Página completa com informações sobre a empresa**:
- **Nossa História**: Fundação em 2020 e evolução da empresa
- **Nossa Visão**: Ser líder em tecnologia de segurança e inovação
- **Nossa Missão**: Empoderar clientes com tecnologia de ponta
- **Nossos Valores**: Qualidade, Inovação, Confiabilidade, Atendimento Excepcional
- **Nosso Time**: 6 membros da equipe fictícia com cargos e descrições

4. **contato.html - Formulário de Contato**
**Página com formulário de contato completo**:
- Campo de Nome Completo
- Campo de Email
- Campo de Telefone
- Seletor de Assunto (Dúvida, Pedido, Reclamação, Sugestão, Outro)
- Área de Mensagem
- Botão de Envio

5. **carrinho.html - Carrinho de Compras**
**Página simulando um carrinho de compras com**:
- Tabela responsiva com produtos
- Campos de quantidade editáveis
- Cálculo de subtotais
- Resumo de compra
- Botão de finalização

### Tecnologias Utilizadas
**Framework CSS**
- Bootstrap 5.3.0 - Framework CSS responsivo que fornece:
- Sistema de grid (container, row, col)
- Componentes pré-estilizados (navbar, cards, botões, formulários)
- Classes de utilitários para espaçamento, tipografia e cores
- Breakpoints responsivos (xs, sm, md, lg, xl, xxl)

### CSS Personalizado
O arquivo assets/css/style.css contém:

- Estilos temáticos (cores de Pânico 6)
- Breakpoints responsivos para diferentes tamanhos de tela
- Estilos para componentes customizados
- Melhorias de acessibilidade
- Estilos para impressão

### Evolução do Projeto

**Parte 1: Pesquisa e Preparação**
Criação da estrutura inicial com HTML5

- Integração do Bootstrap via CDN
- Criação do arquivo CSS externo
- Apresentação básica da empresa

**Parte 2: Layout Responsivo**

- Implementação do sistema de grid (container, row, col)
- Criação de seções temáticas (Hero, Categorias, Destaques)
- Ajustes de responsividade
- Estilos personalizados para seções

**Parte 3: Navegação e Produtos**

- Criação da navbar responsiva
- Desenvolvimento de páginas internas (produtos, sobre, contato, carrinho)
- Criação de 6 cards de produtos
- Implementação de formulários

**Parte 4: Refinamento e Acessibilidade**

- Página institucional completa com equipe fictícia
- Indicação correta de página ativa na navbar
- Refinamento de alinhamento de produtos
- Ajustes responsivos de "mundo real"
- Adição de breakpoints específicos

**Parte 5: Finalização e Publicação**

- Revisão técnica completa de todas as páginas
- Remoção de CSS inline
- Consolidação de estilos em arquivo externo
- Documentação de publicação no GitHub Pages
