# Exercício 4: Loja Fictícia - Projeto Final
Este projeto consiste na criação de uma estrutura completa para uma loja fictícia, desenvolvida em HTML e CSS, seguindo as especificações detalhadas do Exercício 4.
## Checklist Final - Itens Atendidos
- **Página de boas-vindas criada em index.html**: A página inicial foi desenvolvida com uma mensagem de boas-vindas e um link para a galeria de produtos.
- **Galeria com pelo menos 5 produtos em produtos.html**: A página de produtos exibe uma galeria com 6 produtos em formato de cards.
- **Cada card leva para uma página de descrição do produto**: Cada produto na galeria possui um link funcional para sua página de detalhes específica.
- **Cada produto possui valor imaginário**: Os valores dos produtos são exibidos nos cards e nas páginas de detalhes.
- **Página contacto.html criada**: A página de contato foi implementada com informações de contato e um formulário visual.
- **Menu presente em todas as páginas**: O cabeçalho com o menu de navegação está presente e consistente em todas as páginas HTML.
- **Layout com Flexbox**: O menu de navegação e a galeria de produtos utilizam Flexbox para um layout responsivo e organizado.
- **Cards organizados em grade visual**: Os cards de produtos são exibidos em uma grade visual, com flex-wrap para ajuste automático.
- **Hover aplicado em menu, botões e cards**: Efeitos de hover foram adicionados aos links do menu, botões e cards de produtos para melhorar a interatividade.
- **CSS externo em css/style.css**: Todo o estilo do projeto é gerenciado por um único arquivo CSS externo, sem uso de CSS inline ou interno.
- **README.md atualizado**: Este arquivo README.md foi atualizado para refletir a estrutura final e o checklist completo do projeto.
