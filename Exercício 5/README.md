# Loja Responsiva - Scream Store 
Este é o projeto final do Exercício 5, uma loja virtual responsiva com a temática do filme Pânico 5 (Scream 5).
## Objetivo
Desenvolver uma interface de e-commerce completa e responsiva, aplicando conceitos avançados de HTML5 e CSS3, com foco em Mobile First e usabilidade em diferentes dispositivos.
### Decisões de Responsividade
- **Estratégia Mobile First**: Design iniciado para telas pequenas.
- **Breakpoints**: Ajustes específicos para 768px (Tablet) e 1024px (Desktop).
- **Menu Responsivo**: Menu hambúrguer implementado com CSS puro (Checkbox Hack).
- **Layout Adaptável**: Uso de CSS Grid na galeria de produtos (1, 2 ou 3 colunas conforme a tela).
### Lista de Páginas
1. index.html: Página inicial com seção de boas-vindas e introdução.
2. produtos.html: Galeria completa com 5 produtos.
3. produto-notebook.html: Detalhes do Notebook Start.
4. produto-fone.html: Detalhes do Fone Air.
5. produto-smartwatch.html: Detalhes do Smartwatch Fit.
6. produto-camera.html: Detalhes da Câmera Mini.
7. produto-mochila.html: Detalhes da Mochila Tech.
8. portfolio.html: Informações sobre o projeto e tecnologias.
9. contato.html: Formulário de contato completo.
