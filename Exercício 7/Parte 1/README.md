# Ghostface Store - Sistema de Cadastro de Produtos
## Visão Geral do Projeto
Este projeto é um sistema de cadastro de produtos para uma loja fictícia, a Ghostface Store, inspirada no universo do filme de terror Pânico 7. O objetivo principal é permitir o cadastro, visualização e exclusão de produtos utilizando JavaScript para a lógica de negócios e localStorage para persistência dos dados no navegador.

## Funcionalidades

- **Cadastro de Produtos**: Formulário intuitivo para adicionar novos itens ao inventário da Ghostface Store, incluindo nome, categoria, preço e descrição.
- **Listagem de Produtos**: Exibição de todos os produtos cadastrados em uma tabela, com opções para visualizar detalhes e remover itens.
- **Persistência de Dados**: Utilização do localStorage do navegador para armazenar os dados dos produtos, garantindo que as informações não sejam perdidas ao recarregar a página.
- **Navegação Simples**: Uma barra de navegação responsiva permite transitar facilmente entre as páginas de Início, Cadastro, Lista e Contato.
- **Design Responsivo**: A interface é construída com Bootstrap 5, garantindo que o sistema seja acessível e funcional em diferentes tamanhos de tela (desktops, tablets e smartphones).
- **Tema Pânico 7**: Elementos visuais e textuais são customizados para refletir a atmosfera sombria e icônica da franquia Pânico, com fontes e cores que remetem ao terror.

## Tecnologias Utilizadas

- **HTML5**: Estrutura semântica das páginas web.
- **CSS3**: Estilização e design visual.
- **JavaScript**: Lógica de programação e manipulação do localStorage.
- **Bootstrap 5 (via CDN)**: Framework CSS para responsividade e componentes de UI.
- **Google Fonts**: Fontes personalizadas (Creepster, Nosifer) para o tema de terror.

## Como Usar

1. Clone ou baixe este repositório.
2. Abra os arquivos index.html, cadastro.html, lista.html ou contato.html em seu navegador.
3. Utilize a página de Cadastro para adicionar produtos. Eles serão salvos no localStorage do seu navegador.
4. Visualize os produtos na página de Lista.
