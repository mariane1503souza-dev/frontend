# Ghostface Store - Sistema de Cadastro de Produtos
## Sobre o Projeto
Este é o projeto final do Exercício 7, desenvolvido como um sistema completo de gerenciamento de inventário. A aplicação utiliza uma temática imersiva baseada na franquia de terror Pânico 7, oferecendo uma interface moderna, sombria e totalmente responsiva.
## Funcionalidades Principais
- **Persistência Total**: Dados salvos no navegador via localStorage, garantindo que suas informações permaneçam lá mesmo após fechar a página.
- **Dashboard em Tempo Real**: Visualização instantânea do total de itens, valor total em estoque e produtos disponíveis.
- **CRUD Completo**: Cadastro, Leitura, Atualização (Edição) e Exclusão de itens.
- **Busca Inteligente**: Filtre produtos por nome em tempo real.
- **Layout Responsivo**: Experiência otimizada para Desktop, Tablet e Mobile utilizando Bootstrap 5.
## Tecnologias Utilizadas
HTML5: Estruturação semântica.
- **CSS3**: Estilização personalizada com variáveis e animações.
- **JavaScript (ES6+)**: Lógica de negócios, manipulação de DOM e API de Storage.
- **Bootstrap 5**: Framework CSS para componentes e grid responsivo.
- **Google Fonts**: Fontes temáticas (Creepster, Nosifer, Inter).

## Instruções de Uso
- **Página Inicial**: Explore a introdução temática da Ghostface Store.
- **Cadastrar**: Vá para a aba "Cadastro", preencha o nome, preço, estoque e status do item e clique em "Salvar".
- **Gerenciar**: Na aba "Lista", você verá os cards dos produtos. Use a barra de busca para encontrar itens específicos.
- **Editar/Excluir**: Use os botões em cada card para atualizar informações ou remover itens do inventário.
- **Persistência**: Sinta-se à vontade para atualizar a página (F5); seus dados estarão seguros!
